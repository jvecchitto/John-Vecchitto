Import MLS listings

IDX feeds usually only include active listings. To get expired and withdrawn land, run a SmartMLS search (Property type: Lots and Land; Status: Expired, Withdrawn, Canceled; your towns) and export it as CSV. Upload it here and the app matches each listing to its parcel.

Columns are detected by name: Address (or Street Number + Street Name), City, Status, List Price, Original List Price, DOM, List Agent, List Office, MLS #, Expiration / Off Market Date, Acres.
